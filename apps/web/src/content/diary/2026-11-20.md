## 11/16–11/20 工作记录

这周主要在改知问和 AI 分镜，也继续调整注册、后台和模型广场相关的内容。服务器这边整理了三台机器的测试数据，另外清理了一轮本地数据库、编译产物和临时文件。

## 一、坤元知问

知问这周通过项目的部署脚本切到了 DeepSeek Flash。前台固定显示 `KUNYUAN-V0`，原来的模型下拉菜单去掉了，用户进来以后直接使用当前配置的模型。

部署后核对了运行配置和前端产物，公网就绪检查也通过了。不过这轮检查结束时还没有发送实际聊天请求，真实回复这一项还要补上。配置加载成功和模型真正能返回内容，还是得分别确认。

## 二、坤元视算 AI 分镜

### 输入区和等待状态

这周把 AI 分镜往视频聊天里继续整合，统一了普通视频和分镜模式的输入区高度，输入卡片也压缩了一些，右侧面板跟着做了简化。

分镜的「设计中」状态改成单独的状态卡，用动态进度条表示正在等模型返回。这里显示的是等待状态，不是模型已经生成了多少内容。

输入区这部分用 Edge 看过，相关测试一共通过了 568 项。

### 长标题挤压按钮

还处理了分镜标题太长的问题。标题一长，会把网格列撑宽，旁边的「查看分镜」按钮也跟着溢出去。之前看到的是按钮显示不完整，往下查才发现是标题把整列宽度带偏了。

这次把标题限制成单行，超出部分省略，鼠标悬停可以看完整内容，按钮保留完整宽度。改完以后在 Edge 复测，26 项相关测试也通过了。这部分当时还留在本地，没有提交。

### 分镜模型配置

生产环境的分镜草稿生成和对话修改也切到了 `deepseek-flash`。已经确认 API 容器加载了新配置，线上健康检查通过。

真实分镜生成还没有验证，后面需要实际提交一次，看看草稿生成、对话修改和页面状态是否都能正常走完。

## 三、账号、后台和模型广场

注册和登录这边检查了登录、用户隔离以及后台登录子标签。注册表单重新排成邮箱、邀请码、密码、确认密码的顺序，两次密码不一致时直接阻止提交。

前端构建已经通过，不过修改后的浏览器测试还没跑。用户管理页也调了一下「刷新」和「创建用户」两个按钮的对齐。

模型广场这边主要核对数据是从哪里来的，查了模型目录 API 和管理员同步事件接口。还启动了局域网预览，用本机通过局域网 IP 访问，API 健康检查正常。其他设备能不能访问还没有实际试，不能只看本机能打开就算完成。

## 四、GPU 服务器测试数据

这周核查了三台服务器的测试数据，把 4 个小归档解压后推到了基准测试仓库的 `main`。仓库里现在可以直接浏览 626 个 JSON、CSV 和日志文件，README 也补了入口，后面查数据就不用先下载压缩包再找。

两台 6000D 已经确认在内网能互相 `ping` 通。不过 NCCL 通信还没验证，现在只能确认基础网络连通，多卡、多机之间实际通信的情况还得继续测。

## 五、本地环境整理

本地也整理了一轮。先查了项目数据库的位置，清空并重建了本地 Vanta PostgreSQL，另外清理旧的 Rust 编译产物和临时文件。清理后 C 盘释放了约 4.9 GiB，D 盘约 49.7 GiB。

几个项目做下来，编译产物和临时文件积累得还是挺快的。这周先清掉一批，后面也得留意各个项目的数据和产物放在哪里，避免需要排查问题时还得重新找。
