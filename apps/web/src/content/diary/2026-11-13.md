## 11/9–11/13 工作记录

这周继续做 runji 和官网的调整。runji 主要改模型广场，整理 API Key 的使用流程，也讨论了域名部署和备案。官网换了一批图片，调整导航、轮播和生态合作页。除此之外，还发布了一版海克斯大乱斗助手，做了一些宣传文案和工具调研。

## 一、runji

### 模型广场和登录页

模型广场这周继续调分页和排序。国产模型整体放在海外模型前面，百川单独放到列表最后。这里厂商信息有 ID，也有中文名和英文名，排序时都要对应上，否则同一家厂商可能因为名字写法不同，被排到不同的位置。

登录页也恢复了原来的蓝色配色。这一轮主要还是把已有页面继续改顺，模型多起来以后，列表怎么排、翻页以后怎么显示，都得再看一下。

### API Key 流程

这周也看了现有 API Key 怎么调用、怎么测试，并参考 Vanta 整理了一版交互方案。包括生成密钥时的弹窗、生成以后复制、列表里的掩码显示，还有权限、有效期和撤销确认。

这部分暂时停在方案阶段，还没有把新版流程全部做出来。先把生成、保存、测试到撤销这一串操作想清楚，再去改页面。

### 上线准备

另外讨论了 `runji.cloud` 的部署和备案填报，整理网站用途的描述。网站里的企业 AI 服务介绍、模型目录、API 文档和登录后的工作空间，都需要在说明里交代清楚。这周主要做的是部署和填报准备，还不能算正式上线完成。

## 二、坤元官网

### 产品和解决方案图片

官网这周把模型服务和解决方案页的 8 张图片换成了压缩版。发布以后看了三个页面的新版入口，也检查了图片地址，8 张图片都能通过 HTTPS 正常加载。

生态合作页也改了布局，让左边的圆形节点和右边的卡片垂直居中。之前两边内容的高度不同，摆在一起有些错位，这次一起调整了。

### 导航和轮播

生态合作页的「立即申请合作」按钮修了一个重复点击的问题。第一次点能滚到联系方式，再次点击时却没有反应。这次补了相同位置下重复点击的滚动处理。

正式的 GPU 风格轮播图和相关前端修改也提交到了官网 `dev`，提交是 `750337a`。模型服务的应用场景区域另外做了一笔调整，也单独推送了。

官网这边改动比较散，图片、布局、跳转都涉及到了。发布后除了看页面有没有变化，还得点一下入口、看一下资源能不能加载，免得本地看着正常，线上却漏了一张图或者一个链接。

## 三、海克斯大乱斗助手

这周梳理了后面的升级方向，也公开发布了 `v0.1.5` Windows 免安装包，并核对了配套的 SHA-256 校验文件。

另外修了 Windows 启动脚本的换行问题。修完以后实际启动了一遍，确认 Vite 就绪、Rust 编译完成，应用能打开并驻留系统托盘。脚本这类问题平时不显眼，但第一次拿到项目的人会直接卡在启动上，所以这次把启动过程也走了一遍。

## 四、其他工作和工具调研

P800 这边主要围绕首字延迟的测试数据起草宣传标题，先把文案方向整理出来。

工具方面找了并安装 `kubai-ascii-dither` 技能，还看了 `oh-my-pi` 和 RelateAnything。这部分目前主要是了解和尝试，后面再看有没有适合放进现有项目里的用法。
