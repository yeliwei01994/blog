Worker 和 API 可以分开部署、分开扩容。



过本周实践，我对项目中的各组件职责形成了较清晰的认识：
- MySQL 负责保存任务、规则和分析结果；
- Redis 负责任务排队与通知；
- Worker 负责真正执行耗时的视频分析；
- API 负责接收前端请求并提供数据查询；
- YOLO 负责从视频帧中识别目标；
- 前端负责展示任务状态和事件结果。
特别是在 Redis 和 Worker 的关系上，已经能够理解其核心价值：将耗时的视频分析从 API 请求中拆分出来，避免上传接口长时间阻塞，并为后续多 Worker 并行处理提供基础。
