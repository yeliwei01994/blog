# 日志链接新标签页打开：设计

## 目标

日志正文中的所有 Markdown 链接在新标签页打开，避免读者离开当前文章。

## 范围

- 仅处理文章详情页 `.article-body` 内由 Markdown 生成的链接。
- 每个链接设置 `target="_blank"` 和 `rel="noopener noreferrer"`。
- 不改变目录锚点、站点导航、相邻文章或其他页面的链接行为。

## 实现

`DiaryArticlePage` 已在渲染后的 effect 中处理日志正文 DOM。扩展该 effect，遍历文章容器内的锚点并设置上述属性。这样会覆盖现有和未来文章，无需编辑 Markdown 文件或生成的文章数据。

## 测试与验证

- 新增页面测试，确认日志正文链接带有新标签页和安全属性。
- 确认页面外的目录和相邻文章链接不受影响。
- 运行目标测试、类型检查和生产构建。
