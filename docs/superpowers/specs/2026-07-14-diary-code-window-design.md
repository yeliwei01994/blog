# 日记代码块窗口式呈现设计

## 目标

让日记 Markdown 中的标准 fenced code block（例如 ```` ```rust ````）在发布页显示为接近参考图的窗口式代码卡片：浅色背景、圆角、顶部三色控制点、语言标题、复制按钮和横向滚动，同时保持现有 Markdown 写作方式不变。

## 方案

采用纯 CSS 配合现有的 `CodeCopyButton.astro` 客户端脚本，不引入代码高亮依赖或新的 Markdown 容器语法。

- 通过 `pre code` 的 `class` 读取语言标识；有语言时显示大写语言名，无语言时显示 `PLAINTEXT`。
- 在 `pre` 顶部增加窗口标题栏和三色装饰点。
- 保留复制功能，但将按钮放置在标题栏右侧，以图标/短文本形式提供清晰的可访问标签。
- 使用 CSS counter 显示行号；代码正文保持原有文本，不改变复制结果。
- 为亮色和暗色主题分别提供可读的背景、文字和边框颜色。
- 小屏幕下保留横向滚动，避免代码被压缩或溢出页面。

## 影响范围

- `src/layouts/DiaryLayout.astro`：为代码块注入语言元信息和窗口标题结构，并保留复制逻辑。
- `src/styles/editorial.css`：替换现有代码块样式，增加窗口标题栏、行号、按钮和响应式规则。
- `tests/`：增加对代码块元信息/页面结构的回归覆盖（若现有测试工具不适合 Astro 渲染，则至少通过构建和静态产物检查验证）。

## 验证标准

1. 不带语言标识的代码块显示 `PLAINTEXT`。
2. 带语言标识的代码块显示对应的大写语言名。
3. 代码可横向滚动，复制按钮仍能复制纯代码文本。
4. 亮色与暗色主题下文字、背景和按钮保持可读。
5. `npm test`、`npm run check` 与 `npm run build` 通过。
