# 现代内容优先视觉改版

## 目标

将 FORM / FUTURE 从强烈的粗野编辑部视觉，调整为克制、现代、内容优先的开发者个人博客。页面应当更易读、更有层次，并在桌面与手机上保持一致的视觉秩序。

## 视觉方向

- 暖白纸张背景配深墨蓝文字，使用低饱和靛蓝作为唯一交互强调色。
- 标题使用具备阅读气质的衬线字体，正文使用清晰的无衬线字体。
- 使用细浅边框、轻微阴影和适度圆角区分信息层级；不使用厚重黑边、霓虹、渐变或玻璃拟态。
- 动效只用于链接、卡片和主题切换的 150–250ms 反馈，并尊重 `prefers-reduced-motion`。

## 设计 Token

| 角色 | 浅色主题 | 深色主题 | 用途 |
| --- | --- | --- | --- |
| 页面背景 | `#FCFBF8` | `#101828` | 全局画布 |
| 表面 | `#FFFFFF` | `#172033` | 卡片、输入与局部面板 |
| 主文字 | `#162033` | `#F4F7FB` | 标题与正文 |
| 次级文字 | `#667085` | `#AAB4C5` | 日期、说明与辅助信息 |
| 边框 | `#E2E8F0` | `#2B3850` | 卡片与分隔线 |
| 强调色 | `#5B6CFF` | `#9AA7FF` | 链接、当前导航、焦点与主要操作 |

间距采用 4px 基础单位，页面区块使用 48–96px 的层级间距；常规交互目标不低于 44px。

## 页面设计

### 首页

- 顶部使用纤细、固定高度的站点栏：文字 Logo、导航与主题开关。
- Hero 左侧只使用主标题“记录学习、工作与项目实践”；右侧仅保留不含口号的抽象几何装饰，避免新增素材与加载成本。
- 最近日记采用三列卡片，第一项视觉上稍强但不破坏阅读顺序；卡片包含日期、标题、摘要和明确的文本链接。
- 首页底部以“关于这个博客”为引导，使用简短说明并链接到关于页；页脚只保留站点名称、说明和导航，不使用大号标语。

#### 博客说明区

- 使用开放式横向双栏，保留页面的呼吸感，替代大号口号和大面积留白。
- 左侧显示小标题“写在这里”；右侧显示“把工作中的思考、学习中的收获和项目里的经验，整理成可以回看的记录。”，并提供“查看关于页 →”链接。
- 桌面端采用现有约 1:2 的左右列宽；移动端改为上下排列。
- 不使用卡片背景、边框、圆角或阴影；正文使用正常阅读字号，并以分割线与前后区块保持层级。

### 日记列表与文章页

- 日记列表沿用卡片语言，按桌面三列、平板两列、手机单列响应。
- 文章页采用技术博客阅读布局：顶部依次显示日记日期、标题、摘要和发布日期；标题保持清晰但不占满首屏，日期只展示一次。
- 宽屏阅读区从内容容器左侧展开：目录约 192px、正文最大约 768px、间距约 32–64px；目录仅作为弱化的左侧辅助栏，小屏隐藏并回归单列阅读。
- 日记标题最大约 60px，正文一级标题最大约 38px、二级标题最大约 26px，正文保持 16–18px 的舒适阅读尺度。
- 删除右侧 `FORM / FUTURE` 口号栏；保留阅读进度、代码复制和相邻文章导航。
- 文章标题、元数据、封面和相邻文章采用同一视觉层级，不使用旋转印章、描边大字或过强装饰。

### 关于页与留言板

- 关于页采用清晰的双栏介绍，在手机上单列；重点信息使用柔和表面卡片而非大面积装饰。
- 留言板保留现有 API 和表单行为，增加明确的 field label、聚焦状态、提交中/成功/失败状态，以及与日记卡片一致的留言卡片。

## 保持不变的契约

- 所有 Astro 路由、日记 URL、`base` 路径和内容 frontmatter。
- `GET /api/messages`、`POST /api/messages` 和 `PUBLIC_API_BASE_URL`。
- 主题切换能力、无障碍跳转链接与减少动效偏好。
- 现有 `apps/web` 和 `apps/guestbook-api` 目录结构。

## 验收方式

- 在 375px、768px、1024px 与 1440px 宽度下检查无横向滚动、清晰阅读宽度和导航可用性。
- 检查浅色和深色主题的文字、边框、焦点与交互对比度。
- 运行 web 构建、测试和 `astro check`；运行 API 测试与类型检查。
- 视觉检查首页、日记列表、文章页、关于页与留言板。
